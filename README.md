# Mughis Mobile Studio - AI Cloud IDE

Mobile-First AI Powered Cloud IDE & GitHub Code Editor built with Next.js 14, Tailwind CSS, Google Gemini 2.5 Flash API, NextAuth Google OAuth, and Octokit.

## Target Repository
- Owner: `agya1806-blip`
- Repo: `CLOUDFLARE_API_TOKEN`
- Branch: `main`

## Deploying to Vercel
1. Import repository into Vercel.
2. Set Environment Variables:
   - `GOOGLE_CLIENT_ID`
   - `GOOGLE_CLIENT_SECRET`
   - `ALLOWED_EMAIL`
   - `NEXTAUTH_SECRET`
   - `NEXTAUTH_URL`
   - `GITHUB_PAT`
   - `GEMINI_API_KEY`
   - `TARGET_REPO_OWNER` = `agya1806-blip`
   - `TARGET_REPO_NAME` = `CLOUDFLARE_API_TOKEN`
   - `TARGET_REPO_BRANCH` = `main`
